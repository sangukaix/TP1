TP2 가중 체크리스트 v4 수정사항

1. 3번 연관성 분석
- v3의 희소 범주 통합 + Bias-corrected Cramer's V 유지

2. 4~5번 머신러닝
- 3번에서 관련성이 확인된 A1~A10으로 4개 분류 모델 비교
- 최종 모델의 YES/NO 예측 성능 평가는 기존 흐름 유지

3. 6번 주요 요인 종합
- A1~A10 전체 중요도 표시
- 선택 모델의 행동 중요도를 100점으로 환산한 체크리스트 가중점수 표 추가

4. 7번 결론 및 활용
- 기존 상위 5개 문항 방식 삭제
- A1~A10 전체를 사용하는 선생님용 가중 행동 체크리스트 추가
- 선택 모델(Logistic Regression)의 Selection Train 중요도를 기준으로 문항별 점수를 다르게 부여하고 합계를 100점으로 맞춤
- Validation에서 5점 단위 컷을 탐색하여 Class/ASD YES 비율 90% 이상을 처음 충족하는 점수를 고관찰 컷으로 사용
- 중간 구간은 고관찰 컷보다 10점 낮게 설정하여 관찰·기록·보호자 정보 공유 구간으로 사용
- Streamlit 화면에서 교사가 문항을 체크하면 총점이 자동 계산됨

중요한 해석 제한
- 이 100점 점수는 수업 프로젝트용 탐색적 점수이며 공식 AQ-10 채점법을 대체하지 않음
- A1~A10이 Class/ASD Target 생성에 직접 사용되므로 높은 성능/점수 구분은 선별 규칙 재현의 영향이 큼
- 데이터에 아동학대 Target이 없으므로 이 점수로 '아동학대 가능성이 높다'고 판정할 수 없음
- 아동학대 여부는 별도 학대 의심 징후와 기관 절차로 판단해야 함

TP2 가중 체크리스트 v5 수정사항

1. 모든 페이지 상단 여백을 늘려 제목이 상단에서 잘리지 않도록 수정
2. 6번 페이지를 "주요 요인 및 가중치 산출"로 정리
   - 최종 로지스틱 회귀 계수 절댓값 |β| 사용
   - 상대 가중치 = |β_i| / Σ|β|
   - 가중점수 = 상대 가중치 × 100
   - 실제 A10 계산 예시와 전체 10문항 가중점수 표 표시
   - Selection Train → Validation → Final Test 기준 결정 흐름 표시
3. 7번 체크리스트 표는 A1~A10 정확히 10행만 표시
4. 7번 표의 순위·문항·가중점수 열을 가운데 정렬
5. 체크 결과를 오른쪽 연한 초록색 박스에 총점 + 결과내용으로 표시

주의: 이 가중점수는 현재 데이터의 ASD 선별 패턴을 설명하기 위한 프로젝트용 참고점수이며 공식 진단 점수가 아닙니다.

TP2 Dashboard v6 수정사항

1. 사이드바
- 1~7 메뉴 버튼 간격 소폭 확대
- 메뉴 글자 크기 약 1px 확대

2. 전체 화면
- 페이지 상단 여백 확대: 제목이 상단에서 잘리는 현상 보정

3. 1페이지 프로젝트 개요
- 요청한 배경/주의 문구 삭제
- 원본 데이터, 중복 제거 후 등 핵심 수치를 테두리 카드 형태로 변경

4. 2페이지 데이터 전처리
- 제목을 '데이터 전처리'로 변경
- Target 분포/Target 생성 구조 삭제
- 원본 데이터 앞 10행 + ... + 마지막 행 미리보기 추가
- result, age_desc 제외 컬럼을 회색 음영으로 표시

5. 3페이지
- 'p-value 및 연관성 분석'으로 변경
- p-value뿐 아니라 Chi-square/Welch t-test와 연관성 크기(Cramér's V, point-biserial r)를 함께 사용하므로 제목에 연관성 분석 포함

6. 4페이지 머신러닝 모델
- 제목을 '머신러닝 모델'로 변경
- '분류 / 회귀: 분류(Classification)'로 표시
- Logistic Regression이 이진 분류에 사용되는 모델임을 간단히 표시
- 입력 변수 선정/제외 변수/과거 방식 설명 문구 삭제

7. 5페이지 모델 성능 평가
- Confusion Matrix 오른쪽에 TP/TN/FP/FN 뜻과 현재 결과 추가
- Confusion Matrix 색상을 옅은 보라색으로 조정
- ROC Curve 오른쪽에 해석 방법과 현재 AUC 결과 추가

8. 6페이지
- 제목을 '가중치 산출'로 변경
- 로지스틱 회귀계수 절댓값 → 정규화 → 100점 환산 수식과 실제 계산 예시 유지/정리

9. 7페이지
- 분석 결론 삭제
- '문항별 가중점수'로 변경
- 안내/주의 문구 삭제
- 10개 문항만 표시, 순위와 점수 가운데 정렬
- '아동학대 의심 설문조사' 영역을 옅은 주황색으로 구성
- 체크 결과는 오른쪽 연한 초록색 박스에 점수+결과 표시
- '대응방안 리스트'로 변경하고 해석 컬럼 삭제
- 0~49 / 50~59 / 60~100 각 구간의 설정 기준과 Validation/Final Test 실제 수치 추가

TP2 가설검정 v7 수정사항
==========================

1) 3번 페이지를 수업자료 용어 중심으로 다시 구성
- 제목: 3. 가설 검정(통계적 검증)
- 귀무가설(H0) / 대립가설(H1) 표시
- 범주형 변수: 카이제곱 검정(Chi-square)
- 나이(age): 독립표본 t-검정으로 표시
- p-value < 0.05 / p-value >= 0.05 판단 기준을 두 개의 카드로 단순화
- Cramér's V, point-biserial r, Effect Size는 3번 화면에서 제거

2) 결과 표시
- 18개 요인별 검정 방법, p-value, 귀무가설 판정 표 제공
- 행동 문항 / 개인·배경 요인의 p<0.05 요인 수를 간단한 막대그래프로 표시
- 다음 머신러닝 단계에서 p<0.05 요인을 후보로 사용한다는 흐름 유지

3) p-value 계산 원리
- 접을 수 있는 A4 실제 데이터 예시 추가
- Selection Train의 A4 관측도수와 H0 하 기대도수를 나란히 표시
- 카이제곱 계산식과 실제 χ², p-value 결과를 짧게 표시

4) 전체 UI 용어 정리
- 사이드바: 3. 가설 검정
- 분석 흐름: 연관성 분석 → 가설 검정
- 1페이지 흐름도 동일하게 변경

※ 모델 학습 결과와 4~7번 계산 로직은 변경하지 않았습니다.

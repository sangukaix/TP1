TP2 Dashboard v9 수정사항

[공통]
- 모든 페이지 상단 파이프라인 글씨 확대
- 서브헤딩 글씨 확대

[Page 2 데이터 전처리]
- 원본 데이터 섹션을 먼저 배치하고 '미리보기' 표현 제거
- 원본 데이터 아래 ASD 선별 YES/NO별 A1~A10 평균 EDA 그래프 추가
- 전처리 표에 '전처리 종류' 열 추가
- Scaling 미적용 이유 추가

[Page 3 P-value / Hypothesis]
- 상단 카드: 검정 방법 / P-value 결과 중심으로 수정
- 개인·배경 요인은 귀무가설을 '기각하지 못함'으로 표현

[Page 4 머신러닝 모델]
- Validation F1 비교 그래프 가운데 정렬

[Page 5 모델 성능 평가]
- 페이지 설명 문구 삭제
- 290명 → 80% 학습·검증용 232명 / 20% Final Test 58명 다이어그램 추가
- 평가 지표에 한글명 병기
- Confusion Matrix → 혼동행렬(Confusion Matrix)
- ROC Curve → ROC 곡선(ROC Curve)
- 혼동행렬 / ROC 그래프 약 30% 축소

[Page 6 가중치 산출]
- 페이지 설명 문구 삭제
- beta(β), sigma(Σ) 수식 기호 제거
- 회귀계수 절댓값과 +, ÷, × 중심 계산식으로 변경
- 최종 문항별 가중점수 표 값/헤더 가운데 정렬

[Page 7 결론 및 활용]
- 페이지 설명 문구 삭제
- '최종 설문조사지' 서브헤딩 추가 및 여백 확대
- 설문지 내부 갈색 제목 가운데 정렬
- 학생 이름 입력칸 추가
- 학생 이름이 결과 안내 문장에 자동 반영
- 결과 안내 문장을 약 1.2배 크게 한 음영 강조 박스로 표시
- 대응방안 리스트를 결과 영역 바로 아래에 작게 배치하고 현재 점수 구간 강조

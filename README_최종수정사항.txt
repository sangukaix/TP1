TP2 Dashboard 최종 수정사항

[프로젝트 개요]
- 기존 원본 데이터/분석 구성 중심 화면을 3x2 바둑판형 STEP 결과 요약으로 변경
- STEP 1 데이터 전처리: 292→290명, 간단 EDA, 결과 요약
- STEP 2 연관성 확인: 행동/배경 유의 요인과 주요 P-value 요약
- STEP 3 머신러닝 모델 비교: 4개 모델 F1 표시, 로지스틱 회귀 연한 초록색 강조
- STEP 4 모델 성능 평가: Final Test 지표, 작은 혼동행렬/ROC 요약
- STEP 5 문항별 가중치: 주요 가중점수와 100점 구성 요약
- STEP 6 최종 활용: 설문→가중점수→관찰 구간→대응방안 흐름

[3. 연관성 확인]
- 메뉴/페이지 제목을 '3. 연관성 확인'으로 변경
- 상단 P-value 결과 카드는 유지
- 아래쪽 중복 결과 문구 제거

[4. 머신러닝 모델]
- 로지스틱 회귀 행을 연한 초록색으로 강조
- F1 그래프에서도 로지스틱 회귀를 강조
- 최종 선택 모델 표시 강화

[6. 가중치 산출]
- '3. 100점 환산' 설명 줄 제거
- 계산 예시를 문항별 가중점수 수식 박스의 두 번째 줄로 통합

[7. 결론 및 활용]
- 오른쪽 영역을 하나의 개별 관찰 결과 리포트 카드처럼 정리
- 결과 문구를 더 직관적이고 전문적인 2~3줄 설명으로 변경
- 대응방안 4개 구간은 모두 표시하고 현재 구간만 연한 초록색으로 동적 강조
- 오른쪽 카드 하단에 레이더/스파이더 차트 추가
  · ASD 선별 NO 그룹 평균 vs 현재 아동 A1~A10 응답 비교
  · 설문 체크에 따라 현재 아동 그래프가 동적으로 변경
- '점수 구간별 선정 기준'을 접이식 Expander로 변경
  · 50점: 프로젝트 운영 기준
  · 65점: Development NO 최고 64 / YES 최저 67의 분포 경계
  · 80점: Development YES 그룹 중앙값
